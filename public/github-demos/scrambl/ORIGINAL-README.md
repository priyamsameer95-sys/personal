# Scrambl

**Unscramble 18 words against the clock. Same puzzle for everyone, every day.**

A free, privacy-first daily word challenge. No accounts, no ads, no data collection. Runs entirely in your browser.

## How it works

1. Every day at midnight, a seeded random number generator picks 18 words from a curated bank of 400+ common English words
2. The seed is derived from today's date — so everyone who plays on the same day gets the exact same 18 words in the exact same order
3. For each word, the letters are scrambled and you have **10 seconds** to tap them in the correct order
4. At the end, you get a shareable emoji grid (🟩🟥) to post in Slack, Discord, or text to friends

## Why a daily seed matters

The daily seed is the mechanic that makes Wordle, Connections, and every great daily puzzle sticky. When everyone gets the same puzzle, it creates natural social conversation: "I got 14/18, you?"

## Features

- 18-word daily challenge seeded from today's date
- 10-second countdown timer per word
- Tap-to-spell letter tiles with instant feedback
- Shuffle button to re-arrange tiles when you're stuck
- Progress bar showing pass/fail for each word
- Shareable emoji result grid
- Fully client-side — no server, no tracking

## Usage

Open `index.html` in any browser and play.
