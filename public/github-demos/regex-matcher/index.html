📖 How to use this

  • Search Pattern: This box uses a secret code (Regex) to find text. You can type normal words, or click the shortcuts above!
  • Flags: Keep this as g to find all matches, or change it to gi to ignore uppercase/lowercase differences.
  • Your Text: Paste whatever document, log, or paragraph you want to search through. Matches light up instantly in green!

💡 Real Life Use Cases

  • Scraping Contacts: Paste a massive messy document and instantly highlight every single Email Address to copy them out.
  • Data Cleanup: Find all the improperly formatted phone numbers in a giant customer spreadsheet.
  • Security Check: Scan an entire log file for Credit Card numbers or passwords before sharing it with a colleague.
