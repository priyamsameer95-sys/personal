# RegexLive ⚡️

A lightning-fast, purely client-side visual regular expression tester and debugger.

## The Problem
Writing and debugging complex regular expressions is notoriously difficult. Often, developers need to immediately see not just where a pattern matches, but exactly what is being caught in various capture groups, without uploading sensitive strings to a server.

## The Solution (RegexLive)
RegexLive provides instant, real-time visual feedback as you type.
- **Privacy First:** 100% local processing. Your test strings and regex patterns never leave your browser.
- **Visual Capture Groups:** Full pattern matches are highlighted, while individual capture groups are color-coded in layers so you can instantly debug exactly what part of a string is captured.
- **Modern UI:** A clean, dark-mode inspired interface that uses a transparent textarea superimposed over a dynamically generated HTML highlighter, giving a buttery smooth "WYSIWYG" feel.

## Getting Started
Open `index.html` in any modern web browser. No dependencies, no build steps. Just pure HTML, CSS, and JS.
