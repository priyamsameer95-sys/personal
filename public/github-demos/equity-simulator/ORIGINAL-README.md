# EquitySim

A visual, instantly-updating startup exit and equity simulator.

## The Problem
Many employees and early stage founders are given equity percentages (e.g., "0.5%") but don't actually understand how VC Liquidation Preferences work. When a startup exits, the VCs get their money back first. If the exit is small, the employees and common shareholders get absolutely nothing. Existing tools to calculate this are overly complex and use heavy financial jargon.

## The Solution
EquitySim is a visual "napkin math" simulator. You punch in the exit amount, the funding raised, and your percentage, and it instantly graphs the payout waterfall using Chart.js, revealing exactly how much take-home cash you will actually make.

## Usage
No backend required. Just open `index.html` in your browser.
