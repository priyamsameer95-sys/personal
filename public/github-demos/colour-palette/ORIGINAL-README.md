# Color Palette Generator

A simple, fast color palette generator. Press space to get new random colors, and click on any color card to instantly copy its hex code to your clipboard.

## How to run
Simply open `index.html` in your web browser. No build steps required.

## Features
- Press Spacebar to instantly generate a new 5-color palette.
- Click any color to copy the hex code.
- Minimalist, responsive UI.

## Inspiration
Inspired by tools like Coolors, but built as a tiny, lightweight, serverless alternative.
